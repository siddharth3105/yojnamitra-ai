## How to Use New Features

### Save a Scheme
1. Find schemes (complete profile)
2. Click "💾 Save" on any scheme
3. Access saved schemes in sidebar
4. Apply or remove anytime

### Compare Schemes
1. Scroll to "Compare Schemes" section
2. Check 2-3 schemes to compare
3. View comparison table
4. Download CSV if needed

### Use Quick Actions
1. Complete your profile
2. Quick action bar appears at top
3. Click any button for instant action
4. Navigate faster!

### Read Pro Tips
1. Open sidebar
2. Expand "💡 Pro Tips"
3. Read before/during/after tips
4. Apply with confidence!
