## 🏗️ ARCHITECTURE SUMMARY

### AWS Services (7 Total)
1. **AWS EC2** - Compute (t3.micro, live at 13.201.55.10:8501)
2. **Amazon Bedrock** - AI/ML (Qwen3 235B + Titan v2)
3. **Amazon DynamoDB** - NoSQL Database (user profiles)
4. **Amazon S3** - Object Storage (documents, reports)
5. **Amazon Translate** - Multi-language (10+ Indian languages)
6. **Amazon CloudWatch** - Monitoring (logs, metrics)
7. **Amazon VPC** - Network Security

### Data Flow
```
User → EC2 (Streamlit) → Bedrock (Qwen3 + Titan v2) → DynamoDB/S3 → Response
```

### RAG Workflow
1. **Retrieval:** Titan Embeddings v2 creates vectors
2. **Augmentation:** Context builder adds scheme details
3. **Generation:** Qwen3 235B generates personalized response
